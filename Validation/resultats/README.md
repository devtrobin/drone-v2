# Résultats d’essai

Aucun résultat enregistré à la création du dossier.
Créer une note datée par séance avec ID de l’essai, références réelles des composants,
montage, paramètres logiciels, mesures, observations et décision pour la suite.
Ajouter photos ou relevés lorsqu’ils existent ; ne pas remplacer une mesure par une estimation.
Le [protocole](../README.md) donne les essais prévus.
